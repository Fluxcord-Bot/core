# Security policy

Reporting of vulnerabilities MUST NOT happen on the support community or a pull request.

Submit a report through DMing either @jb#1234 or @saber#0001 on Fluxer, or emailing fluxcord-security@jbcrn.dev. Include the affected part of the project, the impact of the vulnerability, any reproduction steps, supporting evidence, and PoC code if necessary/possible. Remove unnecessary secrets such as bot tokens or database credentials.

Vulnerabilities involving accessing the database via a third-party manner, server-side leaks resulting from host misconfiguration, physical attacks, social engineering, phishing, or unsupported environments are out of scope. Please ensure your report applies to the latest commit on the main branch, as older releases or custom forks are not actively patched.
